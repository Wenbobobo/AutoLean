# Riemannian Connections Pilot

This directory is a staging area for the proposed 24-node Riemannian connections and
Levi-Civita discovery graph described in
[`docs/domain-pilot-selection.md`](../../../docs/domain-pilot-selection.md).

It intentionally contains no textbook text and no frozen statement contracts. Source records,
rights policy, mathlib mappings, independent formalization candidates, mutation evidence, and
expert signoff must be created through the Builder fidelity harness before any downstream bundle
is emitted to Prover.

The initial acceptance target is five trial statements. The pilot expands to 20--40 nodes only
after the prerequisite census, rights review, maintainer coordination, and domain-expert gate all
pass.
